su.base#

Base speech functionalities for su: speech recognition and text-to-speech.

This module keeps the strict, explicit speech-processing cores small and pairs each with a flexible public wrapper that casts its inputs through su.casting (Postel’s principle: liberal inputs, strict cores).

The speech features here require the optional speech extra (pip install "su[speech]" — brings SpeechRecognition, pyttsx3 and pyaudio) and the extract_features analysis needs the ml extra (librosa). All such imports are lazy, so import su and the audio-casting / cover-art tools work even when those extras are absent; a precise MissingDependencyError is raised only when a feature that needs them is actually invoked.

static load_audio(file_path, sample_rate=None)[source]#

Load audio to a (waveform, sample_rate) pair.

Accepts any source su.casting.to_waveform() accepts. Uses the lightweight core (no librosa required).

Parameters:

  • file_path (str | Path | bytes | BinaryIO) – Audio source (path, bytes, file-like, waveform, …).

  • sample_rate (int | None) – Target sample rate (None keeps the native rate).

Return type:

tuple[ndarray, int]

Returns:

Tuple of (audio_data, sample_rate), audio as float32 mono in [-1, 1].

Example

>>> import numpy as np
>>> from su.casting import to_wav_bytes
>>> wav = to_wav_bytes(np.zeros(8000, dtype=np.int16), sample_rate=8000)
>>> audio, sr = AudioProcessor.load_audio(wav)
>>> audio.dtype, sr
(dtype('float32'), 8000)

su.base.speak(text_src, *, rate=200, volume=0.9, egress=None, send_to_speakers=True, output_format=None)[source]#

Quick text-to-speech with flexible input and output options.

Parameters:

  • text_src (str | Path | BinaryIO | Iterator[str]) – Any source accepted by su.casting.to_text() (direct text, a text-file path/Path, a file-like object, or an iterable of chunks).

  • rate (int) – Speech rate (words per minute).

  • volume (float) – Volume level (0.0 to 1.0).

  • egress (Callable[[bytes], Any] | str | PathLike | None) –

    Optional output handler:

    • None: no file/bytes output (just speakers, if enabled).

    • str/Path: file path to save audio; the extension (or output_format) selects the encoding.

    • Callable: receives the synthesized WAV bytes and its return value is returned.

  • send_to_speakers (bool) – Whether to also play the audio through the speakers.

  • output_format (str | None) – Explicit output format for a path egress (overrides the extension). Where format does not matter, use a callable egress to pipe the raw bytes.

Returns:

The egress callable’s result, the written Path, or None.

Example

>>> speak("Hello, world!")
>>> speak("Save this", egress="out.mp3", send_to_speakers=False)
>>> audio = speak("Test", egress=lambda b: b, send_to_speakers=False)
su.base.transcribe(audio_src, *, engine='google', debug=False)[source]#

Quick transcription of audio from any supported source.

Non-WAV inputs are transcoded to WAV via su.casting.to_wav_source() (needs ffmpeg) before being handed to the strict recognition core.

Parameters:

  • audio_src (str | Path | bytes | BinaryIO | Iterator[bytes] | dict[str, Any]) – Any source accepted by su.casting.to_audio_segment(), or a {'type': 'microphone', 'timeout': N} dict for live capture.

  • engine (str) – Recognition engine (‘google’, ‘sphinx’, ‘wit’, ‘azure’, ‘houndify’).

  • debug (bool) – Print debug information and re-raise unexpected errors if True.

Return type:

str | None

Returns:

Transcribed text, or None if transcription failed.

Example

>>> text = transcribe("recording.wav")
>>> text = transcribe({'type': 'microphone', 'timeout': 5})
