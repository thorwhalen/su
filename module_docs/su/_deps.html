su._deps

Optional-dependency management for su.

The su package keeps a lightweight core (audio format conversion, waveform handling, cover-art embedding, image handling) installable out of the box, and places heavier or more fragile capabilities behind extras:

  • su[speech] — speech recognition + text-to-speech (SpeechRecognition, pyttsx3, pyaudio).

  • su[ml] — audio analysis / ML feature extraction (librosa, soundfile).

Modules that use an optional dependency import it lazily through require() so that import su never hard-fails and each feature reports a precise, actionable error only when it is actually invoked.

Example

>>> np = require('numpy', extra='ml', feature='waveform analysis')
>>> int(np.array([1, 2, 3]).sum())
6
exception su._deps.MissingDependencyError[source]

Raised when an optional dependency needed for a feature is not installed.

Subclasses ImportError so existing except ImportError handlers keep working.

su._deps.require(module_name: str, *, extra: str | None = None, feature: str | None = None) → ModuleType[source]

Import and return module_name, or raise an informative error.

Parameters:

  • module_name – The importable module name (e.g. 'speech_recognition').

  • extra – The su extra that provides this dependency (e.g. 'speech'). If None, it is looked up from a built-in table when possible.

  • feature – Human-readable name of the feature needing the dependency, used to make the error message actionable.

Returns:

The imported module.

Raises:

MissingDependencyError – If the module cannot be imported, with a message telling the user exactly what to pip install.

Example

>>> mod = require('io')  # a stdlib module always resolves
>>> mod.__name__
'io'
