su

Speech Utils (su): tools for audio I/O, speech recognition, TTS, and cover art.

The package is organised in three layers:

  • su.casting — flexible input/output casting for audio (Postel’s principle): normalise paths, bytes, file-like objects, numpy waveforms, sample lists, or AudioSegment into the strict types the base functions need, and control the output format when it matters.

  • su.base — speech recognition and text-to-speech (needs the speech extra) plus lightweight audio processing.

  • su.cover_art — embed cover images into audio files.

The lightweight core (audio conversion + cover art) works out of the box. Heavier capabilities live behind extras: pip install "su[speech]" (speech recognition + TTS) and pip install "su[ml]" (librosa feature extraction). Those imports are lazy, so import su never fails when an extra is absent.

Example

>>> import su
>>> import numpy as np
>>> seg = su.to_audio_segment(np.zeros(8000, dtype=np.int16), sample_rate=8000)
>>> su.to_wav_bytes(seg)[:4]
b'RIFF'

su.embed_image(audio, image, *, output: str | PathLike | None = None, output_format: str | None = None, overwrite: bool = False, output_dir: str | PathLike | None = None, description: str = 'Cover') → Path[source]

Create an audio file with an embedded cover image.

Parameters:

  • audio – The audio source — a file path, encoded bytes, a file-like object, a numpy waveform / (waveform, sample_rate) pair, or a pydub.AudioSegment (anything su.casting.to_audio_segment() accepts).

  • image – The cover image — a path, raw image bytes, a file-like object, or a PIL Image.

  • output – Explicit output path. If it has no extension, one is added for the resolved format. If None, the path is derived (see module docstring).

  • output_format – Force the output format (e.g. 'mp3', 'flac', 'm4a', 'aiff', 'ogg', 'opus'). Overrides the input-format-follows rule.

  • overwrite – If True, replace the original file in place (only when the output format matches the input’s). Defaults to False — the original is never touched.

  • output_dir – Directory for derived output paths. Defaults to the input file’s directory, or the system Downloads folder for object inputs.

  • description – The cover-art description/title stored in the tag.

Returns:

The Path of the written audio file.

Raises:

ValueError – If the resolved format cannot embed images, or if overwrite conflicts with the resolved output.

Example

>>> # File in, cover embedded, format preserved (mp3 stays mp3):
>>> embed_image("song.mp3", "cover.jpg")
PosixPath('song_with_image.mp3')
>>> # Object in (no format) -> flac in Downloads:
>>> import numpy as np
>>> embed_image(np.zeros(16000, dtype=np.int16), "cover.png")
PosixPath('/Users/you/Downloads/audio_with_image.flac')
>>> # Replace the original in place:
>>> embed_image("song.flac", img, overwrite=True)
PosixPath('song.flac')
su.export_audio(src, output: str | PathLike | None = None, *, format: str | None = None, sample_rate: int | None = None, bitrate: str | None = None, tags: dict | None = None, **export_kwargs)[source]

Egress: encode src to a chosen format, returning bytes or a path.

This is the controllable-output half of the casting layer. Where the output format matters, pass format (or an output path with an extension); where it does not, omit output to get raw bytes you can pipe.

Parameters:

  • src – Any supported audio source.

  • output – Destination path. If None, encoded bytes are returned instead.

  • format – Target format ('wav', 'mp3', 'flac', …). Defaults to the output path’s extension, else 'wav'.

  • sample_rate – Optional resample target for raw-sample inputs.

  • bitrate – Optional encoder bitrate (e.g. '192k' for mp3).

  • tags – Optional metadata tags passed to pydub’s exporter.

  • **export_kwargs – Forwarded to AudioSegment.export().

Returns:

bytes if output is None, else the Path written.

Example

>>> import numpy as np
>>> data = export_audio(np.zeros(800, dtype=np.int16), sample_rate=8000)
>>> data[:4]  # WAV by default
b'RIFF'

su.speak(text_src: str | Path | BinaryIO | Iterator[str], *, rate: int = 200, volume: float = 0.9, egress: Callable[[bytes], Any] | str | PathLike | None = None, send_to_speakers: bool = True, output_format: str | None = None)[source]

Quick text-to-speech with flexible input and output options.

Parameters:

  • text_src – Any source accepted by su.casting.to_text() (direct text, a text-file path/Path, a file-like object, or an iterable of chunks).

  • rate – Speech rate (words per minute).

  • volume – Volume level (0.0 to 1.0).

  • egress –

    Optional output handler: - None: no file/bytes output (just speakers, if enabled). - str/Path: file path to save audio; the extension (or

    output_format) selects the encoding.

    • Callable: receives the synthesized WAV bytes and its return value is returned.

  • send_to_speakers – Whether to also play the audio through the speakers.

  • output_format – Explicit output format for a path egress (overrides the extension). Where format does not matter, use a callable egress to pipe the raw bytes.

Returns:

The egress callable’s result, the written Path, or None.

Example

>>> speak("Hello, world!")
>>> speak("Save this", egress="out.mp3", send_to_speakers=False)
>>> audio = speak("Test", egress=lambda b: b, send_to_speakers=False)
su.to_audio_segment(src, *, sample_rate: int | None = None, sample_width: int | None = None, channels: int | None = None) → AudioSegment[source]

Cast any supported audio representation to a pydub.AudioSegment.

This is the universal ingress (Postel’s “be liberal in what you accept”).

Parameters:

  • src – The audio source. See _SUPPORTED_INPUTS.

  • sample_rate – Sample rate to assume for raw-sample inputs (numpy arrays / lists). Ignored for encoded inputs, which carry their own rate.

  • sample_width – Bytes per sample for raw-sample inputs (inferred if None).

  • channels – Channel count for raw-sample inputs (inferred/defaulted to 1).

Returns:

The audio as an AudioSegment.

Raises:

TypeError – If src is not a supported audio representation.

Example

>>> import numpy as np
>>> seg = to_audio_segment(np.zeros(1000, dtype=np.int16), sample_rate=16000)
>>> seg.frame_rate
16000
>>> to_audio_segment(seg) is seg  # AudioSegment passes through unchanged
True

su.to_waveform(src, *, sample_rate: int | None = None, mono: bool = True, dtype: str = 'float32') → tuple[ndarray, int][source]

Cast src to a (samples, sample_rate) pair for DSP/ML.

Parameters:

  • src – Any supported audio source.

  • sample_rate – Desired sample rate of the returned waveform. For encoded inputs the audio is resampled to it; for raw-sample inputs it is the assumed rate. If None, the source’s native rate is kept.

  • mono – Down-mix to a single channel (returns a 1-D array). If False, a 2-D (num_samples, num_channels) array is returned.

  • dtype – Output dtype. Float dtypes are normalised to [-1.0, 1.0]; integer dtypes keep the raw PCM values.

Returns:

(samples, sample_rate).

Example

>>> import numpy as np
>>> wf, sr = to_waveform(np.ones(1000, dtype=np.int16), sample_rate=16000)
>>> wf.shape, sr, wf.dtype
((1000,), 16000, dtype('float32'))
